# v0.5.0 변경 요약

<!-- markdownlint-disable MD013 -->

비교 기준은 코어 `v0.4.3`과 pi 확장 `0.4.0`입니다.

## 가장 크게 달라지는 점

**며칠 걸리는 작업을 세션이 바뀌어도 이어 갈 수 있게, 작업 카드를 더했습니다.** 카드는 작업의 목표, 사용자 방침, 결정, 현재 상태, 다음 할 일을 담는 인계 문서입니다. 사용자의 말은 모델 요약과 별도로 카드에 원문 그대로 쌓입니다. 켜고 끄는 설정 없이 기본으로 동작합니다.

| 항목 | v0.4.3 | v0.5.0 |
| --- | --- | --- |
| 여러 날 작업 | 사실을 하나씩 `memory_remember`로 저장 | `task_card`로 카드를 저장, 다음 세션 첫 요청에 카드 목록이 나오고 열면 시스템 프롬프트에 고정 |
| 사용자 말 | 대화 수집에만 남음 | 열린 카드에 원문 그대로 기록, 모델이 고칠 수 없음 |
| 지원 클라이언트 | - | pi 확장, Claude Code와 Codex(`memnest hook`), 그 밖의 MCP 클라이언트(`task_card` 도구) |
| 압축 | 요약에 묻힘 | 압축 뒤 카드 규칙과 최근 말을 다시 넣고, 카드가 없으면 한 번 저장을 권함 |
| 현황 확인 | `/memnest`에 기억 개수 | 진행 중인 카드, 마지막 저장 시각, 이 세션이 기록 중인 카드 |

## 카드를 언제 만들고 닫는지

카드 생성은 모델이 판단합니다. 다만 실제 사용에서 모델이 카드를 놓친 경우를 보고, 사용자 말의 단어가 아니라 구조적인 신호에만 한 번씩 알림을 붙입니다.

- 카드가 없을 때 첫 요청에, 이전 작업을 이어 가거나 앞으로 이어질 작업이면 카드를 저장하라는 한 줄.
- 열린 카드 없이 대화가 압축되면 한 번.
- 열린 카드 없이 `memory_remember`를 처음 쓰면 그 결과에 한 줄(pi).
- 열린 카드가 사용자 메시지 8개 동안 저장되지 않으면, 다른 일이면 닫고 같은 일이면 저장하라고 한 번.

측정과 한계는 [작업 카드](task-cards.ko.md)에 있습니다. 횟수가 적은 실측이며, 모델이 카드를 언제나 알맞게 만든다는 보장은 아닙니다.

## 보안

보안 점검에서 나온 항목을 고쳤습니다. 토큰 없이 쓰는 경우 브라우저의 교차 사이트 요청과 DNS 리바인딩 요청을 거절합니다. 브라우저에서 IP 주소나 `localhost`가 아닌 이름으로 접속한다면 `MEMNEST_ALLOWED_HOSTS`에 그 이름을 적어야 합니다. 전체 목록은 [코어 변경 이력](../core/CHANGELOG.ko.md)에 있습니다.

## 업그레이드할 때 알아둘 점

1. **MCP 도구가 6개가 됩니다.** 기억 도구 5개 다음에 `task_card`가 붙습니다. 도구 목록을 고정해 검사하던 프로그램은 고쳐야 합니다.
2. **Claude Code와 Codex는 훅이 필요합니다.** 새 설치는 `SessionStart`와 `UserPromptSubmit`에 `memnest hook --no-recall`을 넣습니다. 이미 설치했다면 `python3 ~/.local/share/memnest/scripts/setup-clients.py`로 추가합니다. Codex는 `/hooks`에서 한 번 신뢰해야 실행합니다.
3. **pi 확장은 `pi install npm:pi-memnest@0.5.0`으로 올립니다.** 고정한 패키지는 `pi update --extensions`로 바뀌지 않으므로 버전을 바꿔 다시 설치합니다. npm의 0.4.0도 새 코어와 함께 동작하지만 작업 카드는 없습니다.
4. **열린 카드는 코어 메모리에만 있습니다.** 코어를 재시작하면 세션별로 열린 카드를 잊고, 다음 요청에서 목록을 다시 보여 줍니다. pi는 세션 기록에서 다시 엽니다.

## 검증 범위

- Rust 테스트 135개와 바이너리 테스트 5개, 정적 검사, 형식 검사, Linux 출시 빌드, 대화 수집 E2E, 설치 스크립트와 패키지 검사, pi 확장 단위 시험과 MCP E2E가 통과했습니다. macOS와 Windows 검사는 GitHub CI에서 돌립니다.
- 작업 카드 알림은 `claude-opus-5-5`로 실제 기억 저장소 복사본에서 쟀습니다. 조건마다 1~4번이라 횟수가 적습니다.
- Claude Code와 Codex 훅은 실제 명령으로 출력만 확인했고, 실제 모델 대화로는 재지 않았습니다.
